Damla Okul eğitim setleri, **Yeni Maarif Modeli** kazanımlarıyla uyumlu hazırlanır. SSS sayfamızdaki genel uyum ifadesinin ötesinde, eğitim seti ürün sayfalarında **Maarif uyum tablosu** yer alır.

## Maarif uyum tablosu nedir?

Eğitim seti (`genre: education`) sayfalarında gövdede yer alan tablo; öğretmene şu soruya yanıt verir:

> Bu set hangi kazanımları, hangi sayfalarda karşılıyor?

| Sütun | İçerik |
| --- | --- |
| Ünite / tema | Set içindeki bölüm |
| Ders | Türkçe, Matematik, Fen vb. |
| TYMM kazanımı | Resmi kazanım metni |
| Sayfa | Setteki sayfa aralığı |
